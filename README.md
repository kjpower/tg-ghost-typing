# Telegram Unsent Message Tracker (Ghost Typing)

Асинхронный скрипт на Python с использованием библиотеки **Telethon**, который отслеживает подозрительную активность в личных сообщениях Telegram. Скрипт фиксирует пользователей, которые начали набирать текст (`UpdateUserTyping`), но так и не отправили сообщение в течение 3 минут (стёрли текст, закрыли чат или передумали).

## 🚀 Как это работает
1. Скрипт работает в режиме полной тишины и не засоряет логи обычным общением.
2. Когда пользователь начинает печатать, запускается изолированная асинхронная задача с таймером на 180 секунд.
3. Если в течение 3 минут от пользователя приходит сообщение, таймер аннулируется.
4. Если время истекло, а сообщения нет — скрипт выводит предупреждение в консоль и записывает его в файл `typing_log.txt`.

## 🛠️ Особенности
* **Изолированный логгер:** Все системные уведомления, сетевые ошибки Windows (`WinError`) и внутренний лог самого Telethon полностью заглушены. На диск и в консоль попадает только чистый результат.
* **Защита от утечки памяти:** Каждая фоновая задача обернута в жесткий таймаут (`asyncio.wait_for`). Память RAM гарантированно освобождается, скрипт не вызывает фризов в системе даже при длительной работе 24/7.

## 📋 Требования
* Python 3.8+
* Telethon
* qrcode
